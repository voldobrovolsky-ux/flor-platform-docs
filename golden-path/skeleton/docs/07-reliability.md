# SLI/SLO и бюджет ошибок

|---|---|---|---|---|---|

## Политика бюджета ошибок
Формулировка по умолчанию (§5.16): при исчерпании бюджета за скользящее окно
все изменения, кроме исправлений инцидентов и уязвимостей, останавливаются
до возвращения в рамки SLO. Отклонение — через ADR.
