# AGENTS.md

Единственный источник инструкций для агента в этом репозитории — `CLAUDE.md`
в корне репозитория. Прочитай его целиком, прежде чем делать что-либо здесь:
это маршрутизатор, а не описание, и он же несёт правила, действующие всегда
(раздел 1 файла).

Файл называется `CLAUDE.md` по историческим причинам (инструмент, которым
велась первая разработка), а не потому что рассчитан на одного производителя
агентов. Правила и маршруты в нём написаны для любого агента, который придёт
работать с этим репозиторием, — не только для Claude Code.
